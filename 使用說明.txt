ExportTranscription 1.1 — 使用說明
==================================

本機、免費的 AI 語音轉逐字稿。解壓縮後雙擊 DuckL-ExportTranscription.exe 即可使用，
不用安裝 Python、不用網路，錄音不會上傳到任何地方。

怎麼用
------
1. 雙擊 DuckL-ExportTranscription.exe
   （右上角可以切換介面語言：中文 / English，會記住你的選擇）
2. 把錄音或影片拖進清單（wav / mp3 / mp4 / m4a / mov / flac …都可以，
   也可以按「加入檔案」，或直接把檔案拖到 exe 圖示上）
3. 設定（通常不用改，會記住上次的設定）：
   - 語言：中文（台灣）/ English / 自動偵測
   - 說話人數：自動；如果你知道有幾個人，直接選人數會分得更準
   - 專有名詞：人名、作品名、術語，用逗號隔開（例如：蘭陵王, Unity, 動線），
     可以大幅提高這些詞被寫對的機率
4. 按「開始轉逐字稿」，完成後會自動打開逐字稿

輸出（存在原檔旁邊，檔名加「_逐字稿」，不會覆蓋任何檔案）
  xxx_逐字稿.txt   逐字稿：每段標時間與說話人，例如
                   [00:01:23] A：可以問一下通道打開大概是怎麼樣的嗎？
  xxx_逐字稿.srt   字幕檔：可以直接掛在影片上，或匯入剪輯軟體

說話人會依第一次開口的順序標成 A、B、C…，
要換成真名，用記事本的「取代」把「A：」換成「小明：」即可。

速度與 GPU 加速
---------------
* 一般筆電 CPU：大約是錄音長度的 1～1.5 倍（22 分鐘的錄音約 25 分鐘）
* 有 NVIDIA 顯卡：視窗上會出現「安裝 GPU 加速」按鈕，按一下就會自動下載
  （約 540 MB）並重新開啟，之後大約快 5 倍（22 分鐘的錄音約 4.5 分鐘）。
  沒有按也能用，會用 CPU。
  沒有網路的電腦：從 GitHub Release 下載 DuckL-ExportTranscription_GPU.zip，
  解壓到同一個位置（裡面的檔案會合併進程式資料夾）即可。
* 第一次處理會先載入模型，約 10～20 秒

準確度
------
* 語音辨識用聯發科 Breeze-ASR-25：針對台灣華語與中英夾雜訓練的 Whisper，
  台灣用語、繁體字、中英混講都比原版 Whisper 準
* 標點由另一個標點模型補上；說話人用聲紋分群
* 仍然是自動辨識：人名、專有名詞、口齒不清或多人同時講話的地方可能有錯，
  重要場合請再對照錄音校對一次
* 錄音品質影響最大：麥克風離講者近、背景安靜，結果會好很多

命令列（選用，可批次）
----------------------
  DuckL-ExportTranscription.exe --cli 錄音.mp4 [-o 輸出檔名(不含副檔名)]
      [--speakers 2] [--lang zh|en|auto] [--hotwords "蘭陵王,Unity"] [--no-srt]
因為是視窗程式沒有 console，訊息會寫到輸出旁的 .log。

備註
----
* Windows SmartScreen 可能提示未簽章：更多資訊 → 仍要執行
* models 資料夾一定要跟 exe 放在一起，不要搬開
* 需要 64 位元 Windows 10 / 11，建議 8 GB 以上記憶體
